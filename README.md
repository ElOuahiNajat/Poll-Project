#  PhosPoll – Survey Management Application

##  Description
**PhosPoll** is a web application designed for managing and analyzing surveys among **OCP** employees.  
It offers a secure authentication system, an intuitive interface, and complete features for creating, managing, and participating in surveys.  
The design emphasizes **green colors** to reflect the organization’s identity and ecological values.

---

##  Features

### Authentication
- Secure login with email and password.
- Role management: **Administrator** and **User**.
- Responsive and clean interface.

###  Administrators
- **Survey management**: create, edit, delete.
- **Add questions**: multiple choice, free text, single choice.
- **User management**: add, edit, delete, search.
- **Dashboard** with real-time statistics.
- **Detailed survey reports**.
- Advanced filtering and search.

###  Users
- View available surveys.
- Participate in surveys online.
- Personal dashboard showing the number of completed surveys.
- Response confirmation and tracking.
