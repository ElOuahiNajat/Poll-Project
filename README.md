# 🌿 PhosPoll – Application de Gestion de Sondages

## 📌 Description
**PhosPoll** est une application web conçue pour la gestion et l’analyse de sondages au sein des employés d’**OCP**.  
Elle propose un système sécurisé d’authentification, une interface intuitive et des fonctionnalités complètes pour la création, la gestion et la participation aux sondages.  
Le design met l’accent sur des **couleurs vertes** afin de refléter l’identité et les valeurs écologiques de l’organisation.

---

## 🚀 Fonctionnalités

### 🔹 Authentification
- Connexion sécurisée avec email et mot de passe.
- Gestion des rôles : **Administrateur** et **Utilisateur**.
- Interface responsive et épurée.

### 🔹 Administrateurs
- **Gestion des sondages** : création, modification, suppression.
- **Ajout de questions** : choix multiples, réponse libre, choix unique.
- **Gestion des utilisateurs** : ajout, modification, suppression, recherche.
- **Tableau de bord** avec statistiques en temps réel.
- **Rapports détaillés** des sondages.
- Filtrage et recherche avancée.

### 🔹 Utilisateurs
- Consultation des sondages disponibles.
- Participation aux sondages en ligne.
- Tableau de bord personnel indiquant le nombre de sondages complétés.
- Confirmation et suivi des réponses.

## 🛠️ Technologies Utilisées

### **Frontend**
- HTML5  
- CSS3 (Design épuré + couleurs vertes)

- JavaScript / jQuery  
- AJAX (Mise à jour dynamique)  

### **Backend**
- PHP (Logique serveur)  
- MySQL (Base de données)  
- XAMPP (Serveur local)

- UML en ligne pour la modélisation
